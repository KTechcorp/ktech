# Shrimply 🦐

A ready-to-run static aquarium storefront.

## Run it locally

```powershell
cd path\to\Shrimply
python run.py
```

`run.py` launches the site at http://127.0.0.1:8000.

## Included

- Responsive storefront
- Shrimp, food and aquarium supplies
- Search and category filter
- Shopping cart saved in browser localStorage
- Quantity controls
- Checkout order preparation through the visitor's email client
- No external Python packages

## Public hosting

This repository includes a GitHub Pages-ready `docs` copy of the website. The public site can be served from the repository's Pages settings using the `docs` folder on the `main` branch.

For a real store, replace the demo email checkout with a real payment provider/backend before accepting money or storing customer data.
